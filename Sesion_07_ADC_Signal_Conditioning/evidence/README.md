# Evidencias pendientes

Guardar en esta carpeta, con estos nombres exactos:

| Archivo | Qué debe mostrar |
|---|---|
| `serial_raw_voltage.png` | Captura del serial (Wokwi o Thonny/MicroPico) donde se vean raw, voltaje, % crudo, % filtrado y estado, idealmente con la perilla en mínimo, medio y máximo |
| `threshold_alarm.png` | Captura con los LEDs en NORMAL (verde), WARNING (amarillo) y ALARM (rojo). Puede ser un collage de 3 capturas o una donde se vean las líneas `[CAMBIO]` en el serial |
| `hardware_photo.jpg` | Foto del montaje físico: Pico 2 W, potenciómetro en GP26 y los 3 LEDs con resistencias de 220 Ω |

Cuando estén los tres archivos, este README se puede borrar.
